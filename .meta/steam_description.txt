DevNoCtrl is a workflow-enhancement mod for Timberborn modders and map developers. It globally  inverts the logic of specific "developer modifier keys" (usually Ctrl, Alt, or Shift) used by the  game's internal tools.

Instead of forcing the user to hold down modifier keys to execute instant/developer actions, this  mod makes the "instant" actions the default behavior. Holding the modifier key will instead revert  the tool to its standard, vanilla behavior.

[h3]How It Works Under the Hood[/h3]
To maintain maximum compatibility and avoid the pitfalls of patching generic base classes (like  BlockObjectDeletionTool) or internal services, this mod intercepts the input layer directly.

It uses a single Harmony Postfix on Timberborn.InputSystem.InputService.IsKeyHeld(string keyId).

If Dev Mode is currently active (CrashSceneLoader.DevModeEnabled is true), the patch intercepts  queries for specific string IDs and applies a logical NOT (!) to the result.

[h3]Intercepted Input IDs[/h3]
The mod specifically targets and inverts the following internal keybind IDs: Building & Tech Tree: PlaceFinished: Makes the building placement tool spawn finished buildings instantly by default  instead of construction sites. InstantUnlock: Makes clicking locked items in the tech tree unlock them instantly for free,  bypassing the science cost and confirmation dialog.

[h3]Deletion & Demolition[/h3]
SkipDeleteConfirmation: Bypasses the "Are you sure?" confirmation dialog when deleting objects by  default. DontRecoverGoods: Causes deleted buildings to instantly vanish without spawning leftover  recoverable material boxes on the ground.

[h3]Agriculture & Planting[/h3]
PlantGrown: Forces the planting tool (or brush) to place fully mature plants by default. PlantSpawned: Forces the planting tool to place the default un-grown prefab. PlantWithYield: Forces the planting tool to place plants that are immediately at maximum yield and  ready for harvest.

[h3]Safety & Compatibility[/h3]
Vanilla Safe: The patch explicitly checks CrashSceneLoader.DevModeEnabled. If Dev Mode is toggled  off, the patch instantly returns the unmodified boolean. It is 100% safe to leave enabled during  standard survival gameplay. Mod Compatible: Because it intercepts InputService.IsKeyHeld, it automatically applies to any  custom tools or mods that rely on these standard Timberborn Dev Mode key strings. Highly Performant: The patch does not use Reflection (AccessTools) at runtime to fetch private  fields or internal methods, resulting in zero overhead during block placement or deletion loops.
